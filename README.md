# SIRUT.in — Aplikasi RT & RW Gratis Berbasis Web (PWA)

**SIRUT.in** adalah platform [aplikasi RT RW gratis](https://sirut.in) berbasis web (*Progressive Web App*) yang membantu pengurus RT, RW, dan Desa/Kelurahan di Indonesia mengelola administrasi warga secara rapi, aman, dan transparan tanpa perlu mengunduh aplikasi berat di Play Store.

- 🌐 **Website Resmi:** https://sirut.in
- 📱 **Panduan Install di HP (Tanpa Play Store):** [Cara Download & Install Aplikasi Data Penduduk RT Gratis di HP](https://sirut.in/blog/cara-download-install-aplikasi-data-penduduk-rt-gratis-di-hp)
- 🛡️ **Legalitas:** Terdaftar Resmi PSE Komdigi RI (`030404.02/DJAI.PSE/10/2026`)

---

## Fitur Utama

1. **[Manajemen Data Warga & KK](https://sirut.in/fitur/manajemen-warga)** — Database penduduk tetap, warga kontrakan/kos, mutasi, dan demografi usia.
2. **[Administrasi Surat Digital](https://sirut.in/fitur/administrasi-surat)** — Pengajuan dan cetak surat pengantar RT/RW online lengkap dengan **[Validasi QR Code](https://sirut.in/fitur/validitas-terjamin)**.
3. **[Pencatatan Keuangan & Kas RT](https://sirut.in/fitur/pencatatan-keuangan)** — Pembukuan iuran bulanan, kas masuk/keluar, dan laporan transparan untuk warga.
4. **[WhatsApp Blast Warga](https://sirut.in/fitur/whatsapp-blast)** — Pengumuman resmi, undangan rapat, dan pengingat iuran otomatis via WhatsApp.
5. **[Keamanan Lingkungan, CCTV & SOS](https://sirut.in/fitur/keamanan-sos)** — Pantau CCTV gerbang/poskamling, lapor tamu, dan tombol darurat SOS.
6. **[Kesehatan & Posyandu Digital](https://sirut.in/fitur/kesehatan-posyandu)** — Pencatatan imunisasi, balita, ibu hamil, dan lansia.
7. **[Etalase Ekonomi & UMKM Warga](https://sirut.in/fitur/ekonomi-umkm)** — Direktori promosi usaha dan produk warga sekitar.
8. **[Penyaluran Bansos Digital](https://sirut.in/fitur/sosial-bantuan)** — Validasi penerima bantuan sosial agar tepat sasaran.
9. **[Manajemen Aset & Inventaris](https://sirut.in/fitur/manajemen-aset)** — Pendataan barang milik RT dan jadwal peminjaman warga.
10. **[Agenda Kegiatan](https://sirut.in/fitur/agenda-kegiatan)** & **[Portal Aspirasi Warga](https://sirut.in/fitur/portal-aspirasi)**.

## Cara Mulai Menggunakan

1. Kunjungi [https://sirut.in](https://sirut.in) melalui browser Chrome (Android) atau Safari (iPhone).
2. Daftar akun pengurus RT/RW secara gratis (mendukung login sekali klik dengan Google).
3. Tambahkan ke layar utama HP (*Add to Home Screen*) agar terbuka seperti aplikasi asli.
4. Baca panduan lengkapnya di [Blog Resmi SIRUT.in](https://sirut.in/blog).
